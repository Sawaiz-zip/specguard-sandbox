# Ledgerly Constitution

## Core Principles

### I. Local-First, Files You Own
Ledgerly is a command-line tool that tracks personal expenses in plain-text files stored on the user's own machine, with no server involved.

### II. Plain Text Is the Source of Truth
Every expense lives in a human-readable file the user can open, edit, back up, and version-control themselves. No hidden database, no lock-in.

## In Scope
- Expense entry, editing, and deletion
- Categories and tags
- CSV and JSON export
- Local summary reports
- Plain-text (TOML/CSV) storage

## Out of Scope
- Cloud sync or a hosted SaaS backend
- User accounts, login, or authentication
- Multi-user collaboration or sharing
- Billing, subscriptions, or payment processing
- A mobile or web application
